# Puljak & Marjanovic - Vue Starter

Minimalni Vue 3 + TypeScript + Tailwind CSS v4 starter za one-page advokatski sajt.

## Pokretanje

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Struktura

- `src/components/layout` - layout komponente
- `src/components/sections` - sekcije sajta
- `src/assets/styles/main.css` - globalni theme/style fajl
